# موقع المستوصف الطبي

موقع تعريفي لمستوصف طبي مبني على **WordPress عربي + قالب Astra + محرر Gutenberg/Spectra**، بتصميم مستوحى من قالب MEDDICAL (فيقما). الموقع يعمل محليًا على جهازك بدون أي تثبيتات خارجية — كل ما يحتاجه موجود داخل هذا المجلد.

- **الجهة**: Alkhaleejy Medical Company
- **النطاق**: <https://alkhaleejy-group.com/>
- **التصميم المرجعي**: [MEDDICAL — Figma](https://www.figma.com/proto/CC8kA7S0mhffrgE4abwRtS/) (كحلي `#1F2B6C` + أزرق `#159EEC` + خط Cairo)
- **اللغة**: عربي بالكامل مع دعم RTL
- **آخر تحديث**: 2026-08-19

---

## 1) تشغيل الموقع

انقر نقرًا مزدوجًا على:

```
start-site.cmd
```

سيفتح الموقع تلقائيًا على: **http://localhost:8080**

| الرابط | الوظيفة |
|---|---|
| `http://localhost:8080` | الموقع |
| `http://localhost:8080/wp-admin` | لوحة التحكم |

**بيانات الدخول للوحة التحكم:**

- المستخدم: `superuser`
- كلمة المرور: في ملف `credentials.local.md` بجذر المشروع

> 🔒 كلمة المرور **غير مكتوبة في هذا المستودع** عمدًا — الريبو على GitHub وأي كلمة مرور تُكتب فيه تبقى في سجل الإصدارات للأبد حتى بعد حذفها. ملف `credentials.local.md` مستثنى من Git.

**لإيقاف الموقع**: أغلق نافذة `clinic-php-server` من شريط المهام، أو من إدارة المهام أنهِ عملية `php.exe`.

## 2) دليل موظف المستوصف (إدارة المحتوى)

كل المحتوى يُدار من لوحة التحكم بدون أي برمجة. الأقسام في القائمة الجانبية:

### الأطباء
«الأطباء ← إضافة طبيب»: اكتب الاسم، وفي صندوق «بيانات الطبيب» عبّئ المسمى الوظيفي والمؤهلات وأوقات الدوام واللغات، وحدد **التخصص** من القائمة الجانبية، وارفع **صورة الطبيب** (الصورة البارزة). يظهر الطبيب تلقائيًا في صفحة «الأطباء» والرئيسية.

### الخدمات الطبية
«الخدمات الطبية ← إضافة خدمة»: العنوان + وصف مختصر (المقتطف) + صورة. تظهر تلقائيًا في صفحة الخدمات والرئيسية.

### التخصصات
«الأطباء ← التخصصات»: أضف أو عدّل أقسام المستوصف (أسنان، نساء وولادة...). كل تخصص له صفحة تلقائية تجمع أطباءه وخدماته.

### الأخبار والمقالات
«الأخبار والمقالات ← إضافة خبر»: مثل أي مقال ووردبريس. آخر 3 أخبار تظهر في الرئيسية تلقائيًا.

### شركات التأمين
«شركات التأمين ← إضافة شركة»: الاسم + الشعار (الصورة البارزة) + ملاحظات التغطية. تظهر في صفحة «التأمينات المعتمدة» والرئيسية.

### الإعلانات والتنبيهات
«الإعلانات والتنبيهات ← إضافة تنبيه»: اكتب نص التنبيه في العنوان وفعّل خيار «مفعّل؟». يظهر **شريط كحلي أعلى كل صفحات الموقع**. عطّل الخيار لإخفائه. آخر تنبيه مفعّل هو الذي يُعرض.

### إعدادات المستوصف
قسم «إعدادات المستوصف»: أرقام الهاتف والواتساب والبريد والعنوان ورابط خريطة قوقل و**أوقات العمل** لكل يوم. هذه البيانات تظهر تلقائيًا في صفحة «اتصل بنا» وزر الواتساب الثابت وجدول أوقات العمل.

> رقم الواتساب يُكتب بالصيغة الدولية بدون + وبدون صفر البداية، مثال: `966501234567`

### طلبات حجز المواعيد
تصل الطلبات المرسلة من نموذج «احجز موعدًا» إلى: «Fluent Forms ← Entries». *(لاحقًا عند الرفع على استضافة يمكن تفعيل إشعار بريد إلكتروني لكل طلب — يحتاج SMTP).*

## 3) بنية المشروع (للمطور)

```
clinic-website\
├── start-site.cmd          ← تشغيل الموقع محليًا
├── wp.cmd                  ← WP-CLI (مثال: wp.cmd plugin list)
├── router.php              ← موجّه خادم PHP المدمج (روابط دائمة)
├── tools\
│   ├── php\                ← PHP 8.3 محمول (php.ini مضبوط)
│   ├── wp-cli\wp-cli.phar
│   └── seed-*.php          ← سكربتات الإنشاء الأولي (صفحات/نموذج/محتوى)
└── site\                   ← جذر ووردبريس
    └── wp-content\
        ├── database\       ← قاعدة بيانات SQLite (ملف .sqlite — هذا هو كل المحتوى!)
        ├── themes\astra-clinic\    ← القالب الابن (ألوان MEDDICAL + RTL)
        └── plugins\clinic-core\    ← إضافة «إدارة المستوصف»
```

### المكوّنات

| المكوّن | الدور |
|---|---|
| WordPress 7.0.2 (عربي) | إدارة المحتوى |
| SQLite Database Integration | قاعدة بيانات بدون MySQL (ملف واحد) |
| Astra + child theme `astra-clinic` | القالب — الألوان والخط في `style.css` و`theme.json` |
| Spectra + Gutenberg | تحرير الصفحات بصريًا |
| ACF (المجاني) | حقول الطبيب/الخدمة/التأمين — مسجلة برمجيًا في `clinic-core/inc/acf-fields.php` |
| Fluent Forms | نموذج «طلب حجز موعد» (id=3) |
| **clinic-core** (مخصصة) | أنواع المحتوى + التصنيف + صفحة الإعدادات + الشورت كودات + الشريط والأزرار الثابتة |

### الشورت كودات المتاحة داخل الصفحات

```
[clinic_doctors limit="4" specialty="slug"]   شبكة الأطباء
[clinic_services limit="6"]                   شبكة الخدمات
[clinic_specialties]                          شبكة التخصصات
[clinic_insurance]                            شعارات شركات التأمين
[clinic_hours]                                جدول أوقات العمل
[clinic_contact field="phone"]                phone | whatsapp | email | address | map
[fluentform id="3"]                           نموذج الحجز
```

### أوامر مفيدة (من جذر المشروع في CMD)

```
wp.cmd plugin list                  عرض الإضافات
wp.cmd user update superuser --user_pass="كلمة-جديدة"
wp.cmd export                       تصدير المحتوى WXR (للنقل إلى استضافة)
wp.cmd eval-file tools\seed-content.php    إعادة زرع المحتوى التجريبي
```

### النسخ الاحتياطي

انسخ مجلد `site\wp-content\` كاملًا — يحتوي القاعدة (database) والصور (uploads) والقالب والإضافات.

## 4) الرفع على الاستضافة

الموقع منشور على <https://alkhaleejy-group.com/> — **الدليل الكامل في [`RESTORE.md`](RESTORE.md)**.

خلاصته: نرفع نسخة طبق الأصل بدل الاستيراد اليدوي — حزمة `wp-content` كاملة + قاعدة البيانات نفسها، بخطوتين على cPanel. الملفان يُبنيان من `site-mysql\` (نسخة محلية ثانية على MariaDB، لأن القاعدة هنا SQLite والاستضافة MySQL):

```
"C:\PHP\php-8.4.21-nts\php.exe" build\make-db.php
"C:\PHP\php-8.4.21-nts\php.exe" build\make-deploy.php
```

الدليلان الأقدم `CONTENT-DEPLOY.md` (استيراد يدوي عبر WXR) و`SERVER-FIX.md` (إصلاح خطأ قالب Astra) ما زالا صالحين كمرجع، لكن `RESTORE.md` هو الطريق المعتمد.

## 5) المحتوى الحالي تجريبي

الأطباء والخدمات والأخبار والصور الحالية **بيانات تجريبية للمعاينة فقط** — تُستبدل بالمحتوى الحقيقي من لوحة التحكم قبل الإطلاق.
